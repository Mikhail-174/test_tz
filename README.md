# **Тестовое задание: Система учёта работников компании**

Разработана внутренняя система для HR-отдела компании, которая позволит вести учёт работников:
- добавлять новых сотрудников
- просматривать список, обновлять данные
- управлять статусами
Система имеет REST API и админ-панель.

Приложение разработано в соответствии с функциональными требованиями:
- Описана модель данных Worker со всеми требуемыми полями, так же добавлены поля для мягкого удаления записей
- Добавлена модель данных Position - должности

## **TechStack:**
- Python 3.14-alpine3.22
- Django 5 + Django REST Framework
- БД PostgreSQL:15
	
## **Endpoints:**
Приложение поддерживает следующий список эндпоинтов:
	
GET `/api/workers/` — список работников
	Ответы содержат список записей с пагинацией в 7 записей
	Записи содержит только требуемые поля для просмотра
	Добавлена фильтрация по полям is_active и position
		например GET `/api/workers/?position=developer&is_active=true`
	Доступ к этому эндпоинту с методом GET имеют все пользователи
		
---------------------------------------------------------------------
	
POST `/api/workers/`— создание работника

- Ответ с положительным статусом будет получен если пользователь имеет статус Admin
- Запрос на добавление записи может быть такого формата:

`{
"position": {
"name": "Developer"
},
"first_name": "Михаил",
"middle_name": "Петрович",
"last_name": "Валуев",
"email": "exampleuser@example.com"
}`

Успешный ответ:

`{
"message": "Worker created successful!"
}`

----------------------------------------------------------------------
	
DELETE `/api/workers/{id}/` — удаление
- Ответ с положительным статусом будет получен если пользователь имеет статус Admin

DELETE `http://localhost:8000/api/workers/2f155ecd-0238-4ab3-8d90-ffccb1739f6e/`

Успешный ответ

`{
  "message": "Worker with id = 2f155ecd-0238-4ab3-8d90-ffccb1739f6e deleted successfully!"
}`

----------------------------------------------------------------------
	
	
POST `/api/workers/import/` — импорт работников из Excel
- Endpoint принимает Excel файл
- Проверяет обязательные поля
- Валидирует поле email, не принимает записи с коллизией email адреса
- Возвращает отчёт в консоли: сколько записей добавлено, сколько ошибок с описанием
- Пример excel файла есть в папке test_imports
		
----------------------------------------------------------------------
	
GET `/admin`
- В просмотре записей работников добавлены фильтры по ключевым полям
- Добавлен поиск
- Есть возможность для редактирования поля is_acitve прямо из списка
- Добавлен фильтр по полю Developers - работники с "developer" в имени позиции и Recently hired - недавно добавленные работники

## **Installation:**
`docker compose up -d --build`

`docker compose exec web python manage.py migrate --noinput`

`docker compose exec web python manage.py createsuperuser`

введите любое имя и пароль для создания суперпользователя

- username: `root`
- password `1234`

-> Cоздать нового пользователя теперь можно если перейти GET `/admin`

-> Авторизоваться как суперпользователь

-> Нажать на ссылку users

-> Нажать на ссылку add user

-> Создать пользователя с необходимыми полями

Если нужно добавить HR работника, для которого вся эта система создавалась, ему необходимо поставить галочку напротив пункта Staff status, а в пункте Groups добавить группу Admin.
	
Для запуска тестов: `docker compose exec web python manage.py test main_app.tests`
